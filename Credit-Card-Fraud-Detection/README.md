# Credit Card Fraud Detection

This project uses Machine Learning to detect fraudulent credit card transactions.

## Algorithms Used
- Logistic Regression
- Random Forest

## Evaluation Metrics
- Precision
- Recall
- F1-score

## How to Run
1. Place `creditcard.csv` inside `data/`
2. Install requirements:
   pip install -r requirements.txt
3. Run:
   python main.py
