CODSOFT – Data Science Internship Projects

  This repository contains Machine Learning projects completed as part of the CODSOFT Data Science Internship program. The projects focus on solving real-world business and analytical problems using Python and Scikit-learn.

🚀 Projects Included:
1️⃣ Credit Card Fraud Detection

  Built a classification model to detect fraudulent transactions.
  
  Handled class imbalance using SMOTE.
  
  Evaluated performance using Precision, Recall, and F1-score.

2️⃣ Sales Prediction Using Machine Learning

  Developed a regression model to predict product sales based on advertising expenditure.
  
  Compared Linear Regression and Random Forest models.
  
  Evaluated using MAE, RMSE, and R² Score.

3️⃣ Movie Rating Prediction

Built a regression model to predict movie ratings based on genre, director, and cast.

Performed feature engineering and model comparison.

Evaluated using error metrics and R² Score.

🛠 Technologies Used

  Python
  
  Pandas
  
  NumPy
  
  Matplotlib & Seaborn
  
  Scikit-learn
  
  Imbalanced-learn (SMOTE)

🎯 Objective

  To apply Machine Learning techniques to real-world datasets and gain hands-on experience in data preprocessing, model building, evaluation, and business problem solving.

📌 Internship Program

  Completed as part of the CODSOFT Data Science Internship.
