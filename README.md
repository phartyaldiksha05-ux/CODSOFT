📌 About This Repository

  This repository contains Machine Learning projects completed during the CODSOFT Data Science Internship.
  
  The goal of these projects is to apply data preprocessing, machine learning modeling, evaluation techniques, and business problem-solving skills on real-world datasets.

📂 Projects Overview
🔐 1️⃣ Credit Card Fraud Detection
🎯 Objective

    Build a classification model to detect fraudulent credit card transactions.

📊 Key Highlights

  Handled highly imbalanced dataset
  
  Applied SMOTE for balancing
  
  Trained Logistic Regression & Random Forest
  
  Evaluated using Precision, Recall & F1-Score

🛠 Tech Stack

  Python | Pandas | Scikit-learn | Imbalanced-learn | Matplotlib

📈 2️⃣ Sales Prediction Using Machine Learning
🎯 Objective

  Predict product sales based on advertising expenditure.

📊 Key Highlights

  Performed Exploratory Data Analysis
  
  Built Linear Regression & Random Forest models
  
  Compared models using R², MAE & RMSE

🛠 Tech Stack

  Python | Pandas | Scikit-learn | Seaborn
