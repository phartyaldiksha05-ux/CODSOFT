# 🎬 Movie Rating Prediction (Streamlit + Random Forest)

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- Random Forest Regressor

## How to Run

### Step 1: Install Dependencies
pip install -r requirements.txt

### Step 2: Train Model
cd src
python train_model.py

### Step 3: Run Streamlit App
streamlit run app.py
