# 📊 Sales Prediction Using Machine Learning

## 📌 Project Overview
This project predicts product sales based on advertising expenditure using Machine Learning.

The model uses advertising spend data from:
- TV
- Radio
- Newspaper

It is a Regression problem where the target variable (Sales) is continuous.

---

## 🎯 Objective
To build and compare Machine Learning models that predict sales based on marketing budget.

---

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📂 Dataset Columns
- TV (Advertising budget on TV)
- Radio (Advertising budget on Radio)
- Newspaper (Advertising budget on Newspaper)
- Sales (Target variable)

---

## 🤖 Models Used
- Linear Regression
- Random Forest Regressor

---

## 📊 Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

---

## 🚀 How to Run the Project

1. Install dependencies:
pip install -r requirements.txt

2. Run the main file:
python main.py
